# hxyfront-62001 船舶轮机值班记录

源提示词编号：1

我想做一个面向船舶轮机值班的前端记录系统，轮机员可以记录主机转速、滑油压力、冷却水温、燃油消耗、舱底水状态和异常巡检项。页面需要有值班班次切换、机舱参数看板、异常记录时间线、交接班摘要和按设备筛选的历史记录。数据先保存在浏览器本地，后续方便扩展成船队统一管理。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62001

## 油耗复核闭环

- 保存记录时，按 `相邻两次燃油读数差 ÷（间隔小时 × 主机转速/额定转速）` 折算小时油耗。
- 较同设备上一稳定班次高 20% 自动标记「待复核」，并从交接摘要的确认油耗中剔除。
- 待复核原因未填写时，复检确认无效且本班不能完成交接；工况确认后恢复统计。
- 班次切换、设备筛选、参数看板与本地保存（localStorage）实时同步。
